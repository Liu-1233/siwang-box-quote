## 二、用户怎么操作（三步）

1. **先选客户**：顶部「① 选择客户」→ 下拉选已有客户，或在下面搜索框输入客户名/公司/国家点选；也可以「✎ 手填客户信息」不关联客户库。选完会显示「已关联客户档案」，可点「查看客户资料」。
2. **再选产品**：往下到「产品明细与成本」→ 用搜索框（名称/编码/分类/目数）或分类按钮筛选 → 点产品卡 → 在弹窗里填颜色/材质/型号/数量/单位/单价 → 「加入报价」。
3. **核成本与出单**：每行「内部成本 / 建议价（默认收起，点开编辑）」→ 填成本并确认 → 右侧 A4 预览实时同步 → 「保存修改」/「导出 PDF」。

## 三、已完成

- 客户选择提为第一步（保留原有下拉/搜索/手填三条入口，快照语义不变）
- 五步流程条：1 客户 → 2 报价参数 → 3 产品与成本 → 4 汇总与运费 → 5 订单与条款
- 产品选择：图片网格 + 分类筛选 + 名称/编码/分类/目数搜索 + 临时产品按钮
- 规格选择：颜色 / 材质 / 型号 / 数量 / 单位 / 单价，写入该行「规格描述」，不反写产品库
- 加入后自动定位到新行，并在行内显示规格摘要
- 客户资料只读查看
- 右侧 A4 实时预览联动（加入即出现在纸面）
